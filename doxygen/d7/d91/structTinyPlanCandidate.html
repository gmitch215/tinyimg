Detailed Description

One distinct way to run a plan, as the budget ladder's levers combine.

tiny_plan_resolve walks one path through these, cheapest give-up first; tiny_plan_enumerate lists all of them so a chooser can weigh cost against peak memory instead of taking the ladder's order. Candidate 0 is always the plan undegraded, and every degraded bit is relative to it.
