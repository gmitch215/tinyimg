Detailed Description

What tiny_plan_admit is asked.

Every member is a 32 bit unsigned integer, in this order, so a host can write the structure with eight setUint32 calls; tiny_admit_opts_sizeof gives the size to reserve. The last four describe the encoder and price it through tiny_encode_cost_for; the output's channel count is the plan's own.

uint32_t TinyAdmitOpts::scale_milli
