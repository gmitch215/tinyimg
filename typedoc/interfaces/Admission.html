    Interface Admission

    Whether a request fits a CPU budget, and the numbers behind the answer.

    Every figure is in milliseconds and already multiplied by the machine factor the caller gave, so marginMs is comparable to the budget as it was passed in. The upper bound is a prediction under exchangeability on the machine the model was calibrated on, not a guarantee.
